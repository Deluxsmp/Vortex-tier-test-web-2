# Vortex Tier v2
Homepage and Rankings are now separate pages.

- `index.html` = compact landing page like the supplied Vortex screenshot.
- Clicking **View Rankings** opens `rankings.html`.
- `rankings.html` is the full leaderboard view, with Overall selected by default.
- Gamemode tabs, search, regions, player skins and tier badges are included.
- Edit player data in `app.js`.

Deploy all files together to Vercel, Netlify or GitHub Pages.
